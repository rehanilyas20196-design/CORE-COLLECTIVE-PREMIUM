\# Image to Three.js



Use this skill when working on image-to-3D or interactive Three.js product experiences.



\## Goals



\- Create premium 3D product experiences.

\- Use Three.js / React Three Fiber where appropriate.

\- Keep the experience optimized for e-commerce.

\- Maintain responsive behavior.

\- Avoid unnecessary heavy assets.

\- Follow the existing project's design system.



\## Workflow



1\. Inspect the existing product page.

2\. Identify the product image and required 3D experience.

3\. Determine whether the image can be represented as a 3D model or visual effect.

4\. Implement the experience using the project's existing stack.

5\. Optimize loading and rendering.

6\. Test desktop and mobile behavior.

7\. Do not break existing e-commerce functionality.



\## Important



Before adding new dependencies, inspect package.json.



Prefer existing project libraries when possible.



Keep the implementation production-ready.
